This is a cheat sheet of official remote [[Model Context Protocol|MCP]] servers: the address you paste into Claude, ChatGPT, Codex, Cursor, or any other MCP client to connect that service. Every address below was tested live on October 16, 2026, by sending it the same opening request an AI client sends. A server that wants you to sign in answers with an OAuth challenge; an open one answers with its name and tools. Anything that didn't answer correctly was left off. Most of these sign-ins are free; the service's own plan, fees, and limits still apply.

Addresses change. When in doubt, check the vendor's own documentation, and remember that connecting a server gives an AI the same powers you have in that account. My own setup is on [[Connections]].

How to add a server

Claude and Claude.ai: open the Connectors settings, add a custom connector, paste the address, and sign in. ChatGPT: turn on developer mode in settings, add the address as a connector, and approve the sign-in. Claude Code: run claude mcp add --transport http NAME ADDRESS. OpenAI Codex: add two lines to ~/.codex/config.toml:

[mcp_servers.basecamp]
url = "https://mcp.basecamp.com/mcp"

Local servers worth knowing

Some official servers run on your own machine instead of at a web address. Google's Google Analytics MCP server is read-only and labeled experimental, and runs through Python. Screaming Frog's SEO Spider can serve MCP to clients on the same computer. Basecamp's command-line tool can serve MCP locally too, alongside its hosted connector above.

What didn't make the list

Addresses I tried for Plaid, Jotform, Shopify's developer docs, Strava, Spotify, Uber, Zoom, Mailchimp, and Microsoft 365 didn't answer as MCP servers today. Some of those services offer connectors inside Claude or ChatGPT through other routes, and some have servers at addresses I didn't find. They will be added when they answer.
