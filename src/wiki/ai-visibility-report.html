This is the running scorecard for one of my [[Connections|lab tools]]: a small tracker on [[Pinebox]] that asks an AI assistant the same sixteen questions a prospect might ask, then records whether the answer names me and which websites it cites. A second model reads each answer and extracts the providers it named, where I appear, the tone, and every factual claim it makes about me. The questions stay the same from run to run, so the numbers compare. Each run costs real money, about $1.60 to $1.90 in API fees, so it runs only when I start it.

What's published is the scorecard, every question, and every claim about me with my check of it. The raw answers stay private because some of them name other people who never asked to be in a report.

Method

Each question goes to Claude with web search turned on. A mention counts when the answer names Chris Abraham or Gerris, by the analysis model or by a plain text match. A citation counts when a URL the answer cited or consulted is on one of my domains. Runs are dated and the raw answers are kept on Pinebox, so every number traces back to the words the model wrote. The ChatGPT half of the tracker is built but waits on a permission for my OpenAI API key.
