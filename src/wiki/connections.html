This is the running inventory of every service my AI tools can reach, and through what. Some connections are MCP servers, the [[Model Context Protocol]] connectors that let an AI client call a service's tools directly. Others are ordinary REST APIs with a key or an OAuth token kept in a file on [[Pinebox]]. Secrets never go into chat or git, and anything that sends, submits, or spends waits for my yes.

OpenAI Codex, ChatGPT, and Claude.ai

Codex on Pinebox has the Screaming Frog MCP server and a Gmail connector. ChatGPT and Claude.ai carry their own connectors on my accounts; they aren't inventoried here yet.

On the way

  • Basecamp. I am moving from Basecamp 2 to Basecamp 5, choosing which projects to migrate. Basecamp 5 has a refreshed API with official SDKs, a command-line tool, agent Skills, and an official MCP connector at https://mcp.basecamp.com/mcp, included with every account, for ChatGPT, Claude, Cursor, and Grok.

Worth adding

  • Google Analytics. Google publishes an official MCP server for Analytics. It is read-only and labeled experimental, and it would let any of these clients pull GA4 reports directly.
  • Google's managed MCP servers. As of April 2026 Google listed more than 50, including Gmail, Drive, Calendar, People, Chat, BigQuery, and Maps Grounding Lite for place and routing data.
  • Google's Developer Knowledge MCP server, which answers from Google's official documentation.
  • Search Console. There is a full API but no official MCP server that I could find, so it would be a Pinebox script like the Places one.
