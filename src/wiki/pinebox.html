Pinebox is the server behind most of Chris Abraham's projects: a DigitalOcean droplet he reaches over SSH from his ThinkPads. [[Blackbox]] lives there, along with its data, its sign-in tokens, and its timers. The four GitHub Pages sites and this weblog are built there with Claude Code before they are pushed.

What runs on it

  • [[Blackbox]], with its SQLite database and the writing folders it may read.
  • Timers: the sign-in keepalive at 6:45 and 18:45, the 11:45 PM day close, and the nightly encrypted backup at about 3:30 AM.
  • Alpine, the mail program Blackbox hands drafts to; Chris presses Ctrl+X to send.
  • Site builds for hillmole.com, thechrisabrahamshow.com, christopherabraham.com, gerriscorp.com, and chrisabraham.net.
  • Lighthouse in a micromamba environment. Until October 16, 2026, the droplet had 1 GB of memory and Lighthouse ran one page at a time; it now has 4 GB.

Continuity and safe operations

The server origin story documents a small SSH-accessible text workstation that grew from mail and writing into an AI-assisted tool host. The agent's account of arriving illustrates how package logs, source files, repositories and handoffs reconstruct the previous session's work. Before changing anything, identify the host, verify the relevant service and inspect the current configuration.

Record backups, timers, log locations and relevant recovery procedures without publishing secrets or personal data. Keep build output reproducible. Use [[Static weblog operations and publication checks]] for public website deploy checks, and [[AI editorial provenance and agent handoffs]] for handing work between assistant sessions.

Habits

Secrets live in files on pinebox with owner-only permissions and never in chat or git. Because laptop and server windows look alike, instructions that must run on the server start with a hostname check. Commands that need sudo are run by Chris in his own terminal.
