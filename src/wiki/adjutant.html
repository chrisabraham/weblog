Adjutant is the working name for a public spin-off of [[Blackbox]], agreed on October 1, 2026 and waiting until Blackbox has had a few more weeks of real use. The pitch is a command-line chief of staff for people whose memory doesn't hold on to things, built quickly with Claude Code and meant to be read and borrowed. Chris thinks of it as show-and-tell, an example rather than a product: no roadmap, no support promises.

Plan

  • A separate public repository with fresh history, so nothing private comes along.
  • The same engine as Blackbox, with Chris' name, clients, data, prompt, and server details moved into private configuration first.
  • A demo that runs with no accounts or keys, using the fakes the test suite already has.
  • A release script that refuses to publish if it finds client names, personal paths, or secrets.

The patterns

  1. An outside authority (Todoist) plus a local append-only history.
  2. Deterministic plain English first, tested by replaying your own message history.
  3. Minutes as data, with supersede and strike instead of delete.
  4. Briefs: gather a packet, make one model call, store the result.
  5. "What am I forgetting," with snoozes that remember why.
  6. Outside actions only on a human yes, with the email client as the send button.
  7. A model per job, with fallbacks and a cost ledger.
  8. Tests that run the real CLI against fakes in a throwaway home folder.
  9. An encrypted nightly backup with a tested restore.
  10. Secrets and data that cannot reach git.
