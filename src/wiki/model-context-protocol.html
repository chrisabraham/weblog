The Model Context Protocol, usually just MCP, is an open standard for connecting AI tools to other software. A service publishes an MCP server that describes its tools, such as "search jobs" or "create an event," and any MCP client can call them on your behalf after you sign in. It is the reason one connector from a company works in Claude, ChatGPT, Codex, and Cursor alike. Anthropic introduced it in November 2024 and on December 9, 2025 donated it to the Agentic AI Foundation, a fund under the Linux Foundation that Anthropic co-founded with Block and OpenAI.

Remote and local servers

A remote server lives at a web address and uses OAuth, so signing in is like any "connect your account" button: Upwork's is at mcp.upwork.com/mcp and Basecamp's at mcp.basecamp.com/mcp. A local server runs on your own machine and talks to the client directly; the Screaming Frog server on [[Pinebox]] is one, and so is the official Google Analytics server.

How Chris uses it

[[Blackbox]] talks to Upwork through Upwork's MCP server with the official Python SDK, and Claude Code and Codex reach Gmail, Calendar, Drive, Todoist, Slack, and more through connectors. The full list is on [[Connections]].
