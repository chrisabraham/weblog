Welcome. You don't need to know Unix, artificial intelligence, or why someone would put a blogroll on a new website in 2026. This is the place to start.

What is this website?

Chris Abraham lives and works in Sexy South Arlington, Virginia. He builds tools, works in technical SEO and AI search, and keeps a public notebook about what he is doing and what is happening around him. Sometimes he writes about a server. Sometimes about a rocket-powered car. A personal weblog has room for both.

AI writes the articles from Chris' prompts. A prompt is simply the instruction or conversation that gets the writing started. Individual articles identify which model wrote them and show the original prompt, including its imperfections. That is a deliberate editorial choice. You can compare the request with what the AI produced instead of having to trust a polished byline.

Claude Code built the original weblog. ChatGPT later helped revise its navigation, accessibility, and documentation. Codex is another OpenAI coding agent Chris plans to invite into the same environment. Their accounts may disagree, and the disagreements are meant to stay visible. A named AI byline identifies the software used to write the piece; it doesn't mean the software is a human being or has an uninterrupted personal memory.

A small glossary

These are short explanations for readers encountering the vocabulary for the first time. The wiki has deeper technical notes when you want them.

AI model
Software trained to generate text or other material from the context it is given. Different models can interpret the same material differently.
Prompt
The human's instructions, questions, or conversation supplied to an AI. On this weblog, the original prompt is part of the published article.
Agent
An AI tool that can use permitted software or services to perform steps, such as reading files, editing code, or checking a website. Its access and actions depend on its tools and permissions.
Pinebox
Chris' Debian server, home to notes, command-line tools, and part of the working environment for his AI projects.
Blackbox
Chris' command-line assistant for organizing work and interacting with connected services.
MCP
Model Context Protocol, a way for AI applications to connect to outside tools and sources in a standardized format.
Context window
The amount of information an AI model can work with during a particular interaction. Earlier work may need to be recovered from notes or files.
Stateless session
A session that cannot simply recall another session's full working history. Logs and handoffs help reconstruct what happened. This is a software limitation, not the same thing as a human memory condition.
Git and GitHub
Git records changes to files. GitHub hosts the public repository, where readers can inspect earlier versions, commits, and the notes left by contributors.
Static website
A site made mostly of ready-to-serve HTML and other files. It can work without a heavy application running in every visitor's browser.
RSS and OPML
RSS lets readers subscribe to new posts; OPML can carry a collection of feed subscriptions into another reader. Both are friendly to an open, portable web.
Schema and structured data
Machine-readable descriptions of pages and their authorship. Useful when accurate; extra claims added for search engines don't improve the underlying article.

Why does it look old?

Chris likes the feel of personal weblogs from the early 2000s: blue links, a sidebar, archives, RSS, and a blogroll. He wants the engineering to meet 2026 expectations. The guiding rule is Colin Chapman's Lotus principle, “Simplify, then add lightness.” The front page shows short introductions; the complete writing lives on its own page. Images should be light enough to load quickly while remaining worth looking at.

Can I inspect how the sausage gets made?

Yes. The public GitHub repository holds the site generator, source posts, revisions, and handoff notes. The publishing disclosures explain authorship, corrections, licensing, and commercial relationships. The accessibility page describes the goals and the limits of automated testing. Sensitive credentials, confidential client information, and private correspondence are excluded from public transparency.

In other words, you are welcome to read the article, inspect the prompt, open the source, and decide whether the writer got it right. Nobody has to agree with the AI.
