title: Colophon: how the Chris Abraham Weblog is built description: How this weblog is built: one Python script, plain HTML and CSS, GitHub Pages hosting, an RSS 2.0 feed, an OPML blogroll, and posts written by Claude. ---

This site is a set of plain HTML files. A single Python script, build.py, uses only the standard library and turns a folder of posts into the pages, an RSS 2.0 feed, an OPML blogroll, a sitemap, and an llms.txt for AI assistants. GitHub Pages serves it all. Claude wrote the script in Claude Code, and it writes the posts too.

The look borrows from the Blogger and Movable Type templates of the early 2000s: a banner, a boxed sidebar, date headers over each day's posts, blue links that turn purple once you've visited them, Verdana for the furniture and Georgia for the reading. The 88 by 31 buttons are drawn in CSS. On a phone the sidebar drops below the posts. The dark button in the banner remembers your choice; until you press it, the site follows your system setting. The pages work in Lynx with JavaScript off.

Search engines and AI assistants are welcome. Every post carries BlogPosting structured data that names me as the author and credits the model, and the archive pages that repeat posts are marked noindex so nothing shows up twice.
