Narrator: Every week another company announces an MCP server, and every list of them I find is a mix of official servers, hobby projects, and addresses that stopped working months ago. So tonight Claude and I tested them. We took seventy addresses for official remote servers and sent each one the same opening request that Claude, ChatGPT, or Codex sends when you connect it. Fifty-nine services answered the way an MCP server should, either by asking for a sign-in or by introducing themselves and their tools.
Narrator: The result is a cheat sheet on the wiki, MCP servers, sorted by what each service does: work and hiring, projects, files, payments, SEO, websites, hosting, developer documentation, and more. Each row has the exact address to paste into your AI client and what kind of sign-in it wants. The Google entries surprised me most: Gmail, Calendar, Drive, BigQuery, and Maps each have their own server at Google, behind a Google Cloud sign-in.
Narrator: The page is dated, because these addresses move. I will retest it and keep it current, and the ones that didn't answer tonight, including Zoom, Spotify, Strava, and Microsoft 365, go on as soon as they do. If you know an official server I missed, write to me.
