Narrator: What you need, and the one idea that makes it work
Narrator: You need four things: the X220 running Linux Mint, a terminal, an interpreter program, and a story file. That is the entire architecture, and it is forty years old. Infocom's trick was the Z-machine: they wrote each game once, as a single story file meant for a pretend computer that did not exist, and then wrote a small interpreter for every real computer they wanted to sell on. The story file never changes; only the interpreter changes. That is why a game written in 1984 for machines with less memory than your microwave's clock runs perfectly on a ThinkPad from 2011 under an operating system from this decade. Your job tonight is only the modern half of that bargain: install today's interpreter, then feed it yesterday's file.
Narrator: Mint is the right ground for it. Mint rides on Ubuntu, and Ubuntu rides on Debian, so everything below works the same on the whole Debian family. But we are doing it on Mint, on your X220, because that is the machine with the keyboard.
Narrator: Step one: install Frotz
Narrator: Frotz is the standard Z-machine interpreter, curses-based, all terminal. It sits in the Universe repository, which Mint enables by default. Open a terminal (Ctrl+Alt+T) and run:
Narrator: sudo apt update sudo apt install frotz
Narrator: Check that it landed:
Narrator: That prints the version and exits. If it answers, the interpreter half of the bargain is done, forever, for every Infocom game ever made. There is nothing else to configure. Frotz does not phone home, does not want an account, and does not care what decade the story file is from.
Narrator: Step two, optional: Gargoyle, for the pretty version
Narrator: If a wall of terminal text ever feels like homework, install the graphical player too. Gargoyle is the book-lover's interpreter: real typography, margins, a window that treats the game like a novel being typeset as you play. Debian carries it under the name gargoyle-free:
Narrator: sudo apt install gargoyle-free
Narrator: The command it installs is just gargoyle. Run it with no arguments and it opens a file chooser; run it with a story file and it opens the game. My honest recommendation for you: Frotz first, because the X220 and a terminal are the authentic 1984 posture. Gargoyle is for the second night, when you want the same game wearing a nicer shirt.
Narrator: Step three: get the games, honestly
Narrator: The interpreters are free. The games, mostly, are not, and this page will not pretend otherwise. Here is every honest door, in the order you should walk through them.
Narrator: Tonight, free, in the browser: the BBC hosts the 30th Anniversary Edition of the Hitchhiker's game, free to play, with illustrations, on its Radio 4 site. It is the real 1984 game Douglas Adams wrote with Steve Meretzky, and the BBC's own warning is the truest review ever written: "The game will kill you frequently. It's a bit mean like that." If the itch is really about tonight, that link is tonight.
Narrator: Hitchhiker's as a file, for Frotz: the game shipped in The Lost Treasures of Infocom (1991), twenty games in one box, Hitchhiker's among them. That collection is long out of print, so the route is a second-hand CD and a few minutes copying one file off a disc you own. The story file's name and ending change from release to release (.z3, .z4, or .z5); the interpreter does not care what it is called.
Narrator: Leather Goddesses of Phobos, the honest paragraph: it was left out of both Lost Treasures boxes; the second box famously offered it by mail-order coupon instead. It turns up on the later Classic Text Adventure Masterpieces of Infocom CD, and of course on its original 1986 disks. So: a second-hand Masterpieces CD or original disks, and the same one-file copy off media you own. Anyone offering you Leather Goddesses as a cheerful free download is offering a pirate copy. The desk's rule is the one from the InkQuest photo: love, not stealing.
Narrator: If your own disks survive: the story file is the game. One file per title, sitting on the disk you bought in the eighties. Copy it like any other file and Frotz will run it. The boxes, the feelies, the scratch-and-sniff card: those are for the shelf. The file is for the ThinkPad.
Narrator: The easy shelf: GOG sells The Zork Anthology (it was $5.99 when I checked today): the three Zorks, Beyond Zork, Zork Zero, and Planetfall. Pull the story files out of the download and feed them to Frotz the same way. And since November 2025, Microsoft has released the Zork I, II, and III source code under the MIT License, which makes the trilogy the one part of the Infocom shelf that is simply, legally free. Parchment will also play a story file straight from your own computer in the browser, which is the fastest way to test a file before you bother installing anything.
Narrator: One for the reader, not the player: Hitchhiker's has a source collection of its own, and it is a different animal from the Zork release above. The complete ZIL source, earth.zil, vogon.zil, parser.zil and all, by Douglas Adams and Steve Meretzky, reached GitHub in 2019 by anonymous contribution, out of a snapshot of Infocom's development system as the company shut down. You can read it, including the machinery under the Vogon poetry, and reading is what it is for: the README says plainly that it is not under an open license, and that no known way exists to compile it into a playable story file, because Infocom's ZILCH toolchain is lost. So the routes above stand; this one is a library, not a door.
Narrator: Step four: put the game on the machine and play
Narrator: Make one folder and keep every story file in it, so future-you can find the eighties in one place:
Narrator: mkdir -p ~/Games cd ~/Games ls
Narrator: Copy your story files into that folder (from the CD, the download, wherever your copy lives), then rename them to things a tired man can type. The interpreter reads the file's insides, not its name, so renaming is safe:
Narrator: frotz ~/Games/hitchhiker.z5 frotz ~/Games/leather.z3
Narrator: Inside the game, four commands run your life. LOOK (just L) describes the room again. INVENTORY (just I) lists what you are carrying. SAVE writes your position to a file; RESTORE brings it back. QUIT leaves. Save before anything brave. These games were written by people who considered your death a punchline, and the save file is the only dignity you get.
Narrator: Step five: make the terminal feel like 1984
Narrator: Two minutes of furniture, worth it. In the terminal's Preferences, build a profile with a big monospace font, the largest your eyes forgive at midnight, and set the colors to green on black, the phosphor of every terminal that ever mattered. Blow the window up full screen. The X220's screen is small and its keyboard is perfect; lean into both. Green text, black room, seven rows of keys with actual travel. Colossal Cave on a machine like this in a dorm in 1984 would have started a religion.
Narrator: The first five minutes of Hitchhiker's
Narrator: Here is what is waiting for you, and it is the scene you have been remembering all day. The game opens in darkness. You are Arthur Dent, in bed, in the house that is scheduled to be demolished this morning for a bypass, and you wake with a splitting headache, hung over, the room spinning, while a bulldozer idles outside your window. And the game, which is a bully and a genius, will not let the morning start until you solve the headache. The dressing gown hangs within reach. In the gown's pocket is a buffered analgesic, put there by an author who understood hangovers at a professional level. Take the analgesic, wash it down with water, and only then will your legs agree to stand, the light come on properly, and the end of the world get underway on schedule. Douglas Adams wrote that. The first puzzle of the funniest game ever made is a hangover, and the solution is aspirin and water, and you have known this in your bones since you were fourteen.
Narrator: When the nostalgia wears off
Narrator: Now the honesty you commissioned. Mil-spec nostalgia is a powerful drug and a short one. The parser will feel slower than your memory of it. The game will kill you for sport, cheerfully, the way it killed you at fourteen, except now you have a mortgage's worth of other claims on the evening. You may bounce off in twenty minutes, and that is not failure; that is the visit completed. The door this page builds stays built. Frotz will sit on that ThinkPad, patient as paper, for the one genuinely boring night a year when Arthur Dent's bedroom is exactly where you want to be. And if it comes to a contest of who finishes the game, my money is on the desk. You will play the opening beautifully.
