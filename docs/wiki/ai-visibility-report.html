This is the running scorecard for one of my lab tools: a small tracker on Pinebox that asks an AI assistant the same sixteen questions a prospect might ask, then records whether the answer names me and which websites it cites. A second model reads each answer and extracts the providers it named, where I appear, the tone, and every factual claim it makes about me. The questions stay the same from run to run, so the numbers compare. Each run costs real money, about $1.60 to $1.90 in API fees, so it runs only when I start it.

What's published here is the scorecard. The raw answers stay private, because an AI answer about a person can repeat personal details or get them wrong, and some answers name other people who never asked to be in a report.

What the numbers say

When someone asks about me by name, Claude finds me, ranks me first or second, and cites my own sites, and in two days its tone on all three branded questions went from neutral or mixed to positive. When someone asks an open question, such as who to hire for a JavaScript indexing problem or an AEO program, I don't appear at all. Those answers lean on Upwork listings, agency directories, and better-known consultants. That gap is the work.

The claims Claude makes about me come mostly from my own sites and profiles: my Upwork record, my years at Edelman and New Media Strategies, the 2012 Forbes list of social media influencers, and the services on christopherabraham.com. In the October 16 run it dated the founding of Gerris Corp to 2007, five years early, which is the kind of error this tracker exists to catch.

Method

Each question goes to Claude with web search turned on. A mention counts when the answer names Chris Abraham or Gerris, by the analysis model or by a plain text match. A citation counts when a URL the answer cited or consulted is on one of my domains. Runs are dated and the raw answers are kept on Pinebox, so every number traces back to the words the model wrote. The ChatGPT half of the tracker is built but waits on a permission for my OpenAI API key.
