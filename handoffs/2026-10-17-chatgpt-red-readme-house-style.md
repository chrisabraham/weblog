## Why this design change

The new README is the public invitation for someone unfamiliar with the AI publication. Color serves as a modest editorial cue: one special entry point among otherwise blue navigation links. Red by itself can resemble an error or warning, so the link remains visibly **bold and underlined** and reads plainly **README**. The rest of the retro design and the existing blue palette remain intact.

CSS adds a dedicated `--readme-accent` instead of reusing `--redlink`, which on this website denotes missing wiki entries. Its normal, visited, hovered, and keyboard-focused appearances are explicit rather than depending on a cascade that previously caused two keyboard accessibility bugs.

**Token values and computed contrast against the paper background:**

| Mode | README ink/accent | Paper | Approx. contrast |
| --- | --- | --- | --- |
| Light | `#a9142b` | `#ffffff` | 7.44:1 |
| Dark | `#ffa0ab` | `#16181d` | 9.19:1 |

Hover and focused links invert the foreground/background to preserve those ratios. A clear focus outline remains. These checks concern computed color values from source, not a claim of complete WCAG certification or user testing.

## Editorial convention and prior material

Chris expressly dislikes an extra s after the apostrophe in the possessive of his first name. New prose and generated publishing material should use **Chris'**. The convention applies to visible site copy, metadata, headings, author biographies, alt text, README files, handoffs, and AI-generated articles. Original human prompts and attributed third-party quotations must remain verbatim.

An audit of the source found occurrences to normalize in the root README, ChatGPT's author page, the visitor README, one ChatGPT bylined post, and an earlier handoff. These have been changed as copyediting rather than concealed substantive revision:

- `README.md`, `src/authors/chatgpt.html`, `src/pages/readme.html`: replace the nonpreferred form in original prose.
- `src/posts/2026-10-16-the-art-of-the-handoff.html`: correct one instance, update the post's `updated:` metadata, and append an attributed October 17 copyediting note. Its original `prompt:` remains unchanged.
- `handoffs/2026-10-16-chatgpt.md`: copyedit three instances and append a dated addendum documenting exactly that operation; original versions remain visible in Git history.
- `AGENTS.md`: make the convention an explicit rule for Claude Code, Codex, ChatGPT, and any future publisher.
- `tools/verify_housekeeping.py`: regression checks reject the nonpreferred possessive in new original content, while excluding verbatim post prompts. Additional CSS tests enforce red tokens and AAA-level ordinary text contrast across light/dark themes.
